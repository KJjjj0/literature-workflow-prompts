# AI Literature Workflow for Codex

This repository contains an open-source, gate-driven literature research plugin
for Codex.

The active release is published on the `main` branch:

- [Source and documentation](https://github.com/KJjjj0/literature-workflow-prompts/tree/main)
- [Plugin README](https://github.com/KJjjj0/literature-workflow-prompts/blob/main/README.md)
- [Security policy](https://github.com/KJjjj0/literature-workflow-prompts/blob/main/SECURITY.md)

Install:

```powershell
codex plugin marketplace add KJjjj0/literature-workflow-prompts@main
codex plugin add ai-literature-workflow@literature-workflow
```

The `master` branch is retained only as the current repository default landing
page. All development and release content is on `main`.
